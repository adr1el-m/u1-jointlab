# JointLab: minimum credible demonstration

**Question:** For one specified PETG and TPU pairing on a stock U1, which connection survives the proposed coax saddle's pull direction, and how does the failure change?

**Prior art and scope.** [Snapmaker material guidance](https://support.snapmaker.com/hc/en-us/articles/34287488318615-Snapmaker-U1-Multi-material-printing-performance) already recommends interlocking in Snapmaker Orca for some pairings. [Published multi-material test work](https://utilityresearchlab.org/assets/research/recycling-mm3dp/chi25-recycling-multimaterial-3d-printing.pdf) already uses plain and shaped interface coupons with tensile tests. Do not claim a new joining principle or standards-compliant strength measurement. The contribution must be an easy-to-reproduce U1 plate, a defined inexpensive fixture, a useful comparison and a functional demonstration. If that package already exists for this use case, narrow or redesign the entry.

1. **Build three conditions.** Plain planar seam (interlocking off); identical seam with Snapmaker Orca beam interlocking; and a CAD-keyed seam (slicer interlocking off). Match outer shape, stock nozzle diameters, material lots, orientation and nominal cross-section. Geometry intentionally differs internally. Verify the preview layer by layer. If beam interlocking applies globally and cannot be restricted to the intended objects, put the conditions on separate plates with matched settings and repeat each condition independently; update the public draft to match.
2. **Before U1 access:** create and slice geometry, document tool assignments, check geometry/grips on available equipment, and draw the force path. Identify every mockup and slicer image as such. No measured U1 performance claims.
3. **On the U1:** pin a slicer and firmware version; record material IDs, TPU hardness, drying condition, temperatures, speeds, layer height, offsets and relevant settings. Pilot with one sample per condition. If successful, print three samples per condition in each of two jobs. Distribute conditions across positions and rotate positions between jobs. Track failed prints by condition; do not silently replace them. Keep original 3MF project and sliced preview.
4. **Measure:** pull samples along a fixed line with repeatable grips and rate guidance. Check the gauge against known weights across the relevant range, record instrument resolution and limits, and distinguish interface separation, specimen fracture, and fixture slippage. Use a bounded test load within the fixture and gauge ratings. Publish individual peak forces in newtons and report median, range and failure mode per condition. Record invalid grip slips and rerun with the reason logged. Results apply to the tested setup.
5. **Demonstrate transfer:** apply the preferred geometry to the weather satellite receiver’s coax saddle. Measure the cable jacket diameter, available mount points, and routing clearance. Check the cable’s minimum bend radius and leave slack at the SDR connector. On an unpowered setup or spare matching lead, compare the selected interlock and plain-seam versions for cable slip, visible connector movement, and jacket deformation under the same documented pull and repeated handling. Define minimum pull retention and cycle target from the chosen cable/device use before testing, and publish how the target was set. Keep this separate from the coupon results.
6. **Package:** versioned project/CAD files, tool assignment and fixture photos, readme, raw data, and a short before/after video. Ask an independent owner to rerun the plate once the project is stable. Include the result even if it disagrees.

**Evidence gate before public sponsorship submission:** labeled explained CAD/slicer screenshots or an honest rough mockup, comparison plan, a stable public review link, and a specific statement of the remaining U1 work. **Cash gate:** documented tests on real U1 hardware and a working, repeatable release.
